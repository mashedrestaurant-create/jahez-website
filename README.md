# JAHEZ Website

موقع طلبات كامل لبراند **جاهز | JAHEZ** مبني باستخدام Next.js وPostgreSQL وDrizzle.

## الوظائف الرئيسية

- منيو عربي وإنجليزي يحتوي على 26 منتجًا.
- البيع بالكيلو الكامل أو الصينية أو عبوة 15 قطعة حسب الصنف.
- سلة طلبات وتسجيل بيانات العميل.
- توصيل للتجمع والرحاب أو استلام.
- منع اختيار موعد أقرب من 24 ساعة افتراضيًا.
- الدفع كاش مفعّل افتراضيًا.
- InstaPay وPaymob مبنيان داخل النظام ويمكن تشغيلهما من لوحة التحكم.
- لوحة تحكم للطلبات والعملاء والمنيو والأسعار والصور ومناطق التوصيل والهوية وطرق الدفع.
- رقم واتساب وعنوان الاستلام ورابط الخريطة ومهلة تجهيز الطلب قابلة للتعديل من لوحة التحكم.

## التشغيل محليًا

1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env.local` وأدخل بيانات قاعدة البيانات والأمان.
3. نفّذ:

```bash
npm ci
npm run db:migrate
npm run db:seed
npm run dev
```

ثم افتح `http://localhost:3000`.

## النشر على Vercel

- ارفع المشروع إلى GitHub.
- اربطه بمشروع Vercel جديد.
- أضف متغيرات البيئة الموجودة في `.env.example`.
- شغّل migrations على قاعدة Neon قبل استقبال الطلبات.

## إعدادات جاهز الافتراضية

- مناطق التوصيل: التجمع والرحاب.
- لا يوجد حد أدنى للطلب.
- مهلة الطلب: 24 ساعة.
- الدفع: كاش فقط.
- رابط نقطة الاستلام مضاف افتراضيًا، ويمكن تعديله من لوحة التحكم. رقم واتساب يُضاف من لوحة التحكم عند الجاهزية.

## ملاحظة الصور

تم استخدام صور الهوية والمينيو والعبوة المرسلة كصور أساسية وفواصل للأقسام. يمكن استبدال صورة كل منتج من لوحة التحكم عند توفر التصوير النهائي.
